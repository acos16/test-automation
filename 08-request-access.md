If you need access to private repositories, you can create a Pull Request (PR) in this public repository (test-automation) following the steps below.:

1. Clone the repository
2. Create a New Branch
3. Create a Request File: 
   - Create a new file named ACCESS_REQUEST.md with below content:
```text
Access Request to REPOSITORY
GitHub Username: YOUR_USERNAME
Reason for Access: PROVIDE_A_BRIEF_EXPLANATION
```
Replace REPOSITORY, YOUR_USERNAME, PROVIDE_A_BRIEF_EXPLANATION with your actual data.

4. Commit and push changes on the previously created branch
5. Create a Pull Request
6. Wait for approval


If you don’t get a response in a few days, consider reaching out via a comment on the PR.
